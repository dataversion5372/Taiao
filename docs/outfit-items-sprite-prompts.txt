TAIAO — OUTFIT-ITEM ICON SPRITESHEET PROMPTS
=========================================================
Six spritesheet prompts covering every item catalogued in
player-character-outfit-items.txt (~124 items). Each sheet has a fixed grid;
cells fill LEFT-TO-RIGHT, TOP-TO-BOTTOM in the numbered order given. Any
trailing cells past the last item are left empty/transparent.

Feed each prompt to the image generator on its own. The SHARED STYLE BLOCK
below applies to ALL six sheets — prepend it (or keep it identical) each time so
the six sheets stay visually consistent and can be sliced on one grid.


=============================================================================
SHARED STYLE BLOCK  (use verbatim at the top of every sheet prompt)
=============================================================================
A single spritesheet of detailed 16-bit-style pixel-art GAME INVENTORY ICONS
on a fully transparent background (alpha, no backdrop, no scenery). Uniform
grid of equal square cells; one item centered in each cell at a consistent
scale with generous padding, none touching cell edges or each other. Clean
readable silhouettes, a soft consistent top-left light source, subtle shading
and a faint rim light, a rich saturated high-fantasy palette. Each garment is
shown AS IF WORN ON AN INVISIBLE MANNEQUIN (hollow inside, no body, no head, no
skin, no face) at a slight 3/4 front angle so its cut is legible; armour,
footwear, accessories, jewellery and held equipment are shown as isolated
objects at the same 3/4 angle. Absolutely NO text, letters, numbers, labels,
borders, grid lines, drop-shadows on the background, or watermarks. Crisp
pixel edges, no photographic blur, no anti-aliased halo.
