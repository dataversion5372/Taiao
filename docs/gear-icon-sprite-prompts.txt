ISLE OF EMBERFALL — TIERED GEAR ICON PROMPTS
=============================================
AUDIT: every tiered weapon, tool, armour piece, jewel, bar and arrow icon
is currently a hue-rotated clone of ONE base sprite (geartiers.js /
content.js defineIcon) — ~450 items sharing a dozen silhouettes. These
sheets replace them with real per-metal art. Integration follows the "gi"
sheet pattern (tools/build_item_icons.py -> item-icons-data.js): slice,
pack 64px cells, repoint ITEMS[id].icon.

==============================================================================
GLOBAL STYLE (paste above every sheet prompt)
==============================================================================
Art style: 16-bit / 'HD-2D' pixel-art inventory icons in the look of the
roguelike NES RPGs and classic RuneScape item sprites. One object
per cell, centred, 3/4 or flat side-on view, bold silhouette, thin dark
outline, limited flat palette with light dithered shading, soft upper-left
light. Fully TRANSPARENT background, no shadows, text or frames. Output:
one PNG per prompt, uniform grid of 64x64 px cells, items in the exact
order listed. Within a sheet the SHAPE stays identical between cells —
only the METAL changes, and each metal must be tellable by colour/finish.
