# What koha funds

*Koha (Māori): a gift, given without obligation, that carries its own
mana — freely given, and freely able to be declined.*

Taiao has no server, no accounts, and no telemetry, so it has almost no
running costs. It doesn't need your money to keep working — the license
guarantees it keeps working regardless of who's paying for what (see
[Licensing](../README.md#licensing)). Nothing about the game is metered,
gated, or worse without support. This page exists so that if a way to give
ever appears, you already know exactly what it does and doesn't pay for.

## What it would actually go toward

- **Generation credits.** New creatures, items and biome art are generated
  with [PixelLab](https://www.pixellab.ai), which is a metered API — every
  new sprite sheet this project ships costs real, small amounts of money.
  More support means more new art gets made, faster.
- **Time.** Writing, world-gen tuning, and reviewing the community's
  workshop proposals (see [GOVERNANCE.md](../GOVERNANCE.md)) are unpaid
  hours today. Support doesn't buy a different outcome, just more of it.

## What it would never go toward

- No server or hosting costs — there aren't any.
- No paywalls, loot boxes, or anything that changes what a non-paying
  player gets. The GPL-3.0/CC BY-SA license makes this a structural
  guarantee, not a promise: anyone could fork the project the moment that
  stopped being true, and keep every asset in it.
- No advertising or telemetry, ever.

## Is there a way to give right now?

Not yet. There's no funding link live at the time of writing — this page
came first, on purpose, so the "why" exists before the "how." When one goes
live, it'll be linked from the README and from `.github/FUNDING.yml`, and
this page will be updated to say so plainly.
