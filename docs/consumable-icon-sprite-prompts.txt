==============================================================================

Kenney.nl roguelike packs and classic RuneScape item sprites. One object

palette with light dithering, soft upper-left light. Fully TRANSPARENT
background, no shadows, text or frames. One PNG per prompt, uniform grid
of 64x64 px cells, items in the exact order listed.
