================================================================================
MONSTER-REAGENT ICON SPRITESHEET — 68 drop-exclusive crafting reagents
================================================================================
These are the materials that only drop from slain monsters and gate the crafting
skills (see js/skills/bestiary-drops.js). One sheet, 68 icons, laid out on a
regular grid so it can be sliced by the content-aware packer (pack_ca.py) and
wired into a self-registering "rg" sheet.

--------------------------------------------------------------------------------
GLOBAL STYLE  (must match the game's existing inventory-item icons)
--------------------------------------------------------------------------------
- Chunky, readable hand-painted RPG *inventory item* icons — the object floating
  alone, three-quarter/front view, as it would appear in a bag slot. NOT a scene,
  NOT on a surface, no ground plane, no props behind it.
- Bold silhouette, clear rim light, single consistent light source from the TOP-
  LEFT, soft ambient occlusion underneath. Slight painterly texture, crisp edges.
- Consistent visual scale: every icon fills roughly 70-80% of its cell, CENTERED,
  with a clear empty margin (gutter) on all four sides. Nothing touches a cell
  edge or bleeds into a neighbour.
- Each "lesser / greater" PAIR is the same object family: the GREATER version is
  visibly more refined / larger / brighter / with a magical glow, so the two read
  as tiers of one material.
- Colour-code by monster theme (listed per block below) so a glance tells you the
  source family.

--------------------------------------------------------------------------------
SHEET / GRID (critical for automated slicing)
--------------------------------------------------------------------------------
- Solid PURE BLACK background (#000000), edge to edge, no vignette, no gradient,
  no border frame, no grid lines drawn.
- Exactly 8 COLUMNS x 9 ROWS = 72 cells, filled LEFT-TO-RIGHT, TOP-TO-BOTTOM.
  The first 68 cells are the icons below (in order); the last 4 cells (row 9,
  columns 5-8) are EMPTY black.
- Square cells, uniform size, generous even spacing between every icon so the
  gutters between icons are clearly empty black.
- NO text, NO labels, NO numbers, NO captions, NO borders, NO drop shadows that
  reach into the gutters. Just the 68 objects on black.
- Suggested canvas: 8*256 x 9*256 = 2048 x 2304 px (or larger, square cells).

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
